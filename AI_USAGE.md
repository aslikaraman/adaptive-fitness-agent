**2026-11-16 – Claude Code (Claude Opus 5.5).** I used Claude Code to turn the course requirements
from the lecture slides into our project plan and to review it for gaps and over-engineering; to
complete the functional flow (exact adaptation rules, filter order, retry rule, undo scope); to define
the layered architecture with automatic layer checks; to justify our pattern set and the rejected
patterns from the slides' Context and Forces (PATTERNS.md); and to write the interface stubs. It wrote
the deliberately naive baseline (`v0-baseline`) and, step by step, the domain models with the
TrainingPlan Composite and its Memento, a first draft of the 50-entry exercise catalog (reviewed
by Claude, 11 entries corrected), the Ollama adapter with its prompts, and the State machine with the
onboarding and plan-generation services and the JSON storage, each with unit tests. It also checked
all files repeatedly against each other, the plan and the assignment slides and fixed the
inconsistencies it found. I approved every change before it was committed; the results are
used in the repository and in our project plan document.
